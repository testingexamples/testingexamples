# Demo Selenium C# Skill

This repo teaches five Selenium locator strategies and four form
interactions against the public page https://testingexamples.github.io/en-001/practice/,
in C#.

Locator strategies, form interactions, and the exact calls used are listed
in `spec/index.md`; the code is `Program.cs`. Keep them in agreement.

Run it with `dotnet run` (see README.md for installing dependencies).

For the general teaching material behind this demo — locating, acting,
waiting, and asserting, plus pitfalls — see
https://github.com/testingexamples/selenium-c-sharp-skill.
