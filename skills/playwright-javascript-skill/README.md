# Playwright JavaScript Skill

This repo is a Claude Code "Skill": a packaged set of instructions that
teaches how to write, explain, debug, and extend Playwright browser
automation code in JavaScript — locating elements, performing actions,
waiting, and writing real assertions with `@playwright/test`. It is not a
runnable demo itself; for runnable demos, see the sibling repos linked
from SKILL.md.

The actual content lives in [SKILL.md](SKILL.md).
