# Selenium Rust Skill

This repo is a Claude Code skill: a reference for writing Selenium-equivalent
WebDriver browser automation in Rust using the [`thirtyfour`](https://crates.io/crates/thirtyfour)
crate. It is not a runnable demo itself — it's teaching material for an
AI coding agent (or a human) to draw on when writing, explaining, debugging,
or extending WebDriver code in Rust.

Note up front: there is no official "Selenium" crate for Rust. `thirtyfour`
speaks the same underlying W3C WebDriver protocol that Selenium uses, and is
the crate this skill teaches.

The actual content lives in [SKILL.md](SKILL.md).
