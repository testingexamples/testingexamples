# Playwright Python Skill

This repo is a Claude Code "Skill": a packaged set of instructions that
teaches how to write, explain, debug, and extend Playwright browser
automation code in Python — locating elements, performing actions, waiting,
and writing real assertions with `pytest-playwright`. It is not a runnable
demo itself; it's a reference Claude Code loads when the task calls for it.

The actual content lives in [SKILL.md](SKILL.md).
