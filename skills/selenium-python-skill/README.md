# Selenium Python Skill

This repo is a Claude Code skill/reference for writing Selenium WebDriver browser
automation code — and real tests — in Python. It is not a runnable demo itself;
it's documentation that teaches an AI coding agent (or a person) how to locate
elements, perform actions, wait explicitly, and write real assertions with
Selenium in Python, grounded in real working examples from this project's sibling
demo repos.

The actual skill content lives in [SKILL.md](SKILL.md).
