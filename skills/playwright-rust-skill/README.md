# Playwright Rust Skill

This repo is a Claude Code skill: a packaged reference that teaches how to
write, explain, debug, and extend Playwright browser automation code in Rust
using the `playwright-rs` crate. It is not a runnable demo itself — for
runnable demos, see the sibling repos linked from `SKILL.md`.

The actual skill content lives in [SKILL.md](SKILL.md).
